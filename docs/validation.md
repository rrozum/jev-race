# Что проверено в версии 0.1.0

Локальная проверка: 29 сентября 2026 года, Linux/WSL, Python 3.12, Docker Desktop и Chromium с WebGL. Это результаты проверки работоспособности, а не сравнение качества моделей.

| Проверка | Результат |
|---|---|
| Python/API/генератор/адаптеры | 34 теста проходят |
| Импорт Godot и Web-экспорт | Собираются локально и внутри Docker |
| Полный браузерный матч | 12 препятствий, все шесть типов; тестовый агент без штрафов, игрок без действий — 12 штрафов |
| Готовность | До нажатия не начинается гонка и нет запросов модели |
| Камеры | Переключение слева/справа и сверху/снизу во время заезда |
| Отчёты | Скачивание HTML и JSON; токена в файлах нет |
| Ошибки и очистка | Неверный токен останавливает заезд; новая игра и обновление удаляют результат и токен |
| Хранилище браузера | Cookies, Local Storage и Session Storage пусты |
| Готовый контейнер | Health check проходит, UID 10001, корневая ФС только для чтения; после заезда нет изменений ФС и записей в логах |
| Настоящий Jev через контейнер | 4 успешных ответа от `jev-1.13.0`; полный матч дошёл до отчёта |

В коротком живом заезде время запросов сервер → Jev составило 501,4 / 274,9 / 255,2 / 283,2 мс. Расчётная стоимость всех четырёх запросов — $0,000073248. Эти четыре измерения не являются гарантией задержки или стабильности API. Jev получил один штраф; человек в этой автоматизированной проверке не выполнял действий.

Общий объём основных игровых файлов — 39,89 МиБ без сжатия, 11,47 МиБ с gzip и 8,39 МиБ с Brotli. Проверка снимков интерфейса выполнена на широком экране и на ширине 390 px. Основной проверенный способ игры — настольный браузер.

## Границы этой проверки

- Laya и LLM-планировщик представлены адаптерами и примерами. Реальные веса Laya и отдельный LLM-сервер в этой проверке не запускались. Отмена и последовательность локального инференса проверены подставной моделью.
- Workflow GitHub Actions добавлен; облачный CI ещё не запускался, репозиторий не опубликован.
- Публичный HTTPS-домен, нагрузочное испытание и полная матрица Safari/Firefox/мобильных устройств пока не проверялись.

В автотестах используются явно названные тестовые агенты. Они не выдаются за ответы Jev. Само приложение не сохраняет результаты этих или пользовательских заездов.
